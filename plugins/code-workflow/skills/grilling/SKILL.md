# 方案追问

## 梳理待定决策

从当前对话提取已明确的目标、约束和决定。找出会影响方案的未决事项，并标明每项决策依赖哪些事实或前置决定。

用可用资料和工具查证事实。需要用户提供的事实才向用户询问。查证期间，继续讨论与该事实无关的问题。把取舍交给用户决定。

## 分轮提问

1. 把前置条件已明确的待定问题放进同一轮。依赖本轮答案的问题留到后续。
2. 给每题编号并写明要决定的事项。附上推荐选项和理由，尽量让用户可以直接确认，也可以提出不同选择。涉及重要取舍时，说明不同选择会改变什么。
3. 发出一轮问题后等待回复。记录确认的决定，保留未答或仍有歧义的问题，再按最新答案重新判断下一轮能问什么。

**Q1 · 分页方式**

这个按创建时间排序、持续有新记录写入的列表接口，是否采用游标分页？

**建议** 采用以创建时间和唯一 ID 为游标的分页，避免新记录写入导致后续页的偏移量变化。

## 确认结论

关键决策都已明确后，简要汇总已定方案和适用条件，请用户确认双方理解一致。等用户确认后，再进入已获授权的实施步骤。
