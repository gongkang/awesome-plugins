# 方案追问

## 明确目标和范围

从当前对话和已有资料提取目标、约束、成功标准和已定事项。意图还模糊时，先问一个开放问题，让用户描述一个真实场景或期望结果。范围明确后，聚焦会改变方案的取舍。

用可用资料和工具核实能查到的事实。需要用户补充时，问具体缺失的信息。查证期间，可以继续问不依赖该事实的问题。

## 分轮提问

1. 先问会改变方向或解锁后续决策的问题。前置条件已明确、彼此独立的问题可以合在一轮。依赖本轮答案的问题留到后续。
2. 用「Q1 · 决策主题」这样的标题给决策题编号，接着写具体问题、推荐选项和理由。有多条可行路径时，说明各自的收益和代价。用户明确委托你决定的细节可以采用合理的默认值，并标明是你的建议。
3. 每轮提问后等用户回复。记下已确认的决定和仍待解决的问题。重要决定改变方向时，先简要复述你的理解，再据此调整下一轮问题。

## 确认结论

等每项关键取舍都有结论或得到用户同意延后，再按方案规模汇总已定方案、成功标准、待验证的假设和延后的事项。请用户确认你的理解。确认后进入已获授权的实施步骤。
