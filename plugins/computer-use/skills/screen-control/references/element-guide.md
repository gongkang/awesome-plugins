# UI 元素识别指南

本文档帮助你在看屏幕截图时准确识别和理解各类 UI 元素。

---

## 一、基础元素类型

### 1. 按钮 (Button)

**视觉特征**：
- 矩形或圆角矩形区域
- 通常有背景色或边框
- 包含文字、图标或两者

**常见样式**：

| 类型 | 视觉特征 | 点击位置 |
|------|---------|---------|
| 主要按钮 | 醒目背景色（蓝/绿） | 中心 |
| 次要按钮 | 浅色背景或仅边框 | 中心 |
| 图标按钮 | 仅图标，无文字 | 图标中心 |
| 文字按钮 | 仅文字，无背景 | 文字区域中心 |
| 悬浮按钮 | 圆形，通常在右下角 | 圆心 |

**识别要点**：
- 悬停效果：鼠标悬停时背景/边框变化
- 禁用状态：灰暗、半透明或不可点击外观
- 按下状态：视觉凹陷或颜色加深

---

### 2. 输入框 (Input/Text Field)

**视觉特征**：
- 矩形区域，通常有边框
- 内部可能有占位文字（灰色）
- 可能有标签在上方或左侧

**常见样式**：

| 类型 | 视觉特征 | 操作 |
|------|---------|------|
| 单行输入 | 扁平矩形 | 点击后输入 |
| 多行输入 | 较高矩形 | 点击后输入 |
| 搜索框 | 带搜索图标 | 点击或输入触发搜索 |
| 密码框 | 输入显示为圆点 | 点击后输入 |
| 带清除按钮 | 右侧有 × 图标 | 点击 × 清空 |

**识别要点**：
- 聚焦状态：边框高亮或有发光效果
- 错误状态：边框变红，可能有错误提示
- 禁用状态：灰色背景，不可输入

---

### 3. 复选框 (Checkbox)

**视觉特征**：
- 小方框 + 标签文字
- 选中时方框内有勾选标记

**状态**：

| 状态 | 视觉特征 |
|------|---------|
| 未选中 | 空方框 |
| 选中 | 方框内有 ✓ 或 × |
| 部分选中 | 方框内有 - 或实心 |
| 禁用 | 灰色，不可交互 |

**点击位置**：方框中心或文字区域均可

---

### 4. 单选按钮 (Radio Button)

**视觉特征**：
- 小圆形 + 标签文字
- 选中时圆内有实心点

**状态**：

| 状态 | 视觉特征 |
|------|---------|
| 未选中 | 空圆环 |
| 选中 | 圆内有实心点 |
| 禁用 | 灰色 |

**特点**：同一组单选按钮互斥，选中一个会取消其他

---

### 5. 下拉选择 (Dropdown/Select)

**视觉特征**：
- 类似输入框的外观
- 右侧有下拉箭头 ▼
- 点击展开选项列表

**操作流程**：
1. 点击下拉框展开选项
2. 点击目标选项
3. 下拉框收起，显示已选值

---

### 6. 开关/切换 (Toggle/Switch)

**视觉特征**：
- 滑动轨道 + 滑块
- 两种状态：开/关

| 状态 | 视觉特征 |
|------|---------|
| 关闭 | 滑块在左/轨道灰色 |
| 开启 | 滑块在右/轨道高亮色 |

**点击位置**：轨道或滑块均可

---

### 7. 滑块 (Slider)

**视觉特征**：
- 横向或纵向轨道
- 可拖动的滑块
- 可能有数值显示

**操作**：拖动滑块或点击轨道位置

---

### 8. 列表 (List)

**视觉特征**：
- 垂直排列的项目
- 每项可能有图标 + 文字
- 可滚动

**状态**：

| 状态 | 视觉特征 |
|------|---------|
| 普通 | 正常显示 |
| 悬停 | 背景高亮 |
| 选中 | 背景色持续高亮 |
| 多选 | 前有复选框 |

---

### 9. 标签页 (Tabs)

**视觉特征**：
- 水平排列的标签头
- 选中标签有高亮/下划线
- 下方显示对应内容

**识别要点**：
- 选中标签：视觉突出
- 未选中标签：颜色较淡
- 关闭按钮：可能有 × 图标

---

### 10. 对话框/弹窗 (Dialog/Modal)

**视觉特征**：
- 居中的矩形区域
- 有背景遮罩（半透明黑色）
- 包含标题、内容、操作按钮

**常见结构**：
```
┌─────────────────────────────┐
│  标题                    [×] │
├─────────────────────────────┤
│                             │
│         内容区域            │
│                             │
├─────────────────────────────┤
│         [取消]  [确定]      │
└─────────────────────────────┘
```

**操作要点**：
- 点击 × 关闭
- 点击背景遮罩关闭（部分支持）
- 点击按钮执行对应操作

---

## 二、复杂交互元素

### 1. 菜单 (Menu)

**特征**：
- 垂直排列的选项列表
- 点击某项可能展开子菜单
- 可能有分隔线

**操作**：
1. 点击触发菜单打开
2. 移动到目标项
3. 点击选中

---

### 2. 工具栏 (Toolbar)

**特征**：
- 水平排列的图标按钮
- 通常在窗口顶部
- 可能有分隔线分组

**识别**：
- 图标代表功能
- 悬停显示工具提示
- 禁用图标灰暗

---

### 3. 侧边栏 (Sidebar)

**特征**：
- 垂直长条区域
- 通常在窗口左侧
- 包含导航项或工具

---

### 4. 状态栏 (Status Bar)

**特征**：
- 窗口底部水平条
- 显示状态信息
- 可能有图标指示

---

### 5. 卡片 (Card)

**特征**：
- 矩形容器
- 有边框或阴影
- 包含图片、标题、内容

**操作区域**：
- 整张卡片可点击
- 或有特定按钮区域

---

## 五、元素状态识别

### 视觉状态速查表

| 状态 | 视觉特征 |
|------|---------|
| **正常** | 标准外观，可交互 |
| **悬停** | 背景/边框变化，可能有提示 |
| **聚焦** | 边框高亮，有光标（输入框） |
| **选中** | 持续高亮背景/边框 |
| **禁用** | 灰色、半透明、不可点击 |
| **加载中** | 旋转图标、进度条、骨架屏 |
| **错误** | 红色边框/文字，警告图标 |
| **成功** | 绿色，对勾图标 |

## 六、定位技巧

### 1. 确定元素边界

```
方法 1：找边界线
- 按钮：边框或背景色边界
- 输入框：边框线
- 列表项：分隔线或交替背景

方法 2：找对比区域
- 文字与背景的对比
- 图标与背景的对比
- 高亮与正常的对比
```

### 2. 确定点击坐标

```
步骤：
1. 识别元素边界
2. 计算边界框的中心点
3. 考虑屏幕缩放比例
4. 给出实际坐标

公式：
中心 X = (左边界 X + 右边界 X) / 2
中心 Y = (上边界 Y + 下边界 Y) / 2
```

### 3. 多显示器情况

```
注意事项：
- 坐标是全局的，跨越所有显示器
- 主显示器左上角为 (0, 0)
- 第二显示器可能在主显示器左边或右边
- 坐标可能为负数（第二显示器在左侧时）
```

## 七、常见陷阱

### 1. 误识别

| 情况 | 正确识别 |
|------|---------|
| 图片上的按钮 | 检查是否有交互区域特征 |
| 装饰性图标 | 检查是否有按钮样式 |
| 广告内容 | 与正常 UI 区分 |

### 2. 重叠元素

```
处理方法：
- 识别遮罩层，先关闭弹窗
- 识别下拉菜单，先选择或关闭
- 识别工具提示，等待消失或移开
```

### 3. 动态内容

```
识别要点：
- 加载动画：旋转圈、骨架屏
- 进度指示：进度条、百分比
- 实时更新：数字变化、状态切换

策略：获取时序帧观察变化
```

## 八、操作决策流程

```
看到画面后的决策流程：

1. 识别场景类型
   └→ 桌面？应用窗口？网页？弹窗？

2. 识别当前状态
   └→ 加载中？稳定？有弹窗？

3. 定位目标元素
   └→ 类型？位置？状态？

4. 确定操作方式
   └→ 点击？输入？拖拽？滚动？

5. 计算坐标
   └→ 边界 → 中心 → 换算实际坐标

6. 执行并验证
   └→ 操作 → 等待 → 获取新帧 → 确认
```

## 十、实际案例分析

### 案例 1：识别登录界面

```
画面描述：
┌─────────────────────────────────┐
│              [Logo]             │
│                                 │
│    ┌───────────────────────┐    │
│    │ 用户名/邮箱           │    │
│    └───────────────────────┘    │
│    ┌───────────────────────┐    │
│    │ ●●●●●●●●              │    │
│    └───────────────────────┘    │
│                                 │
│    ☐ 记住我                     │
│                                 │
│    ┌───────────────────────┐    │
│    │        登 录          │    │
│    └───────────────────────┘    │
│                                 │
│      忘记密码？  注册账号       │
└─────────────────────────────────┘

识别结果：
- 输入框 1：用户名输入，位置 (居中偏上)
- 输入框 2：密码输入，显示为圆点
- 复选框：记住我选项
- 主按钮：登录，醒目样式
- 文字链接：忘记密码、注册账号

操作计划：
1. 点击用户名输入框 → 输入用户名
2. 点击密码输入框 → 输入密码
3. (可选) 点击复选框勾选记住我
4. 点击登录按钮
```

### 案例 2：识别带弹窗的页面

```
画面描述：
┌─────────────────────────────────┐
│  网页内容 (暗淡)                │
│  ┌─────────────────────────┐    │
│  │ 标题              [×]   │    │
│  │─────────────────────────│    │
│  │                         │    │
│  │  确定要删除吗？         │    │
│  │  此操作不可撤销         │    │
│  │                         │    │
│  │─────────────────────────│    │
│  │      [取消]  [确定]     │    │
│  └─────────────────────────┘    │
│  网页内容 (暗淡)                │
└─────────────────────────────────┘

识别结果：
- 背景遮罩：半透明，使底层内容暗淡
- 弹窗：居中，有标题栏
- 关闭按钮：右上角 ×
- 内容区：提示文字
- 操作按钮：取消、确定

操作要点：
- 点击取消或 × 可关闭弹窗
- 点击确定执行删除
- 弹窗关闭后才能操作底层页面
```

---

记住：**识别元素是操作的前提**，准确识别才能正确操作。遇到不确定的情况，先获取时序帧观察变化，再做决策。
